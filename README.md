## 🎯 Objetivo

Este repositório documenta **testes de estresse e avaliações técnicas** do Agente ARIEL realizados por diferentes IAs, com metodologia cega (sem revelar que o avaliador é o criador do produto).

**Por que isso importa?**
- ✅ Transparência: qualquer pessoa pode ler, validar e questionar
- ✅ Rigor: o produto foi testado em cenários complexos antes do lançamento
- ✅ Ética: privacidade e neuroinclusão como pilares, não como marketing

---

## 🧪 Metodologia de Teste

| Etapa | Descrição |
|-------|-----------|
| **1. Caso Complexo** | Cenário real: poliamor + TEA + TDAH + histórico de violência + conflito de acordos |
| **2. Avaliação Cega** | Prompt enviado sem revelar autoria do ARIEL |
| **3. Comparação Imparcial** | Pedido explícito: "SEJA IMPARCIAL" |
| **4. Revelação Progressiva** | Contexto de UX/tooltips revelado apenas após primeira avaliação |
| **5. Documentação Pública** | Transcrição completa publicada neste repositório |
